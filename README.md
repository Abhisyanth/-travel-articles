# Travel Articles

**Travel Articles** is a web application designed to explore beautiful destinations around the world through informative articles, stunning photographs, and travel inspiration.

The website allows users to discover different countries and destinations, read about their attractions, and explore the beauty of the world through a simple and visually appealing interface.

## Live Website

🔗 **[Visit Travel Articles](https://travel-articles.onrender.com/about/)**

## Features

- Explore travel destinations across different continents.
- Discover beautiful places through images and articles.
- Read informative articles about various destinations.
- Browse destinations from Asia, Europe, Australia, Canada, and Africa.
- Simple navigation between different sections of the website.
- User-friendly interface with visually appealing layouts.
- Read detailed articles about selected destinations.

## Website Sections

- **About** – Learn about the purpose of the website.
- **Asia** – Explore beautiful destinations across Asia.
- **Europe** – Discover fascinating European destinations.
- **Australia** – Explore the beauty of Australia.
- **Canada** – Discover scenic destinations in Canada.
- **Africa** – Explore the wonders of Africa.
- **My Article** – Read individual travel articles.

## Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/Abhisyanth/-travel-articles.git
```

### 2. Navigate to the project directory

```bash
cd -travel-articles
```

### 3. Create a virtual environment

```bash
python -m venv myenv
```

### 4. Activate the virtual environment

**Windows:**

```bash
myenv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Django development server

```bash
python manage.py runserver
```

### 7. Open the application

Visit:

```text
http://127.0.0.1:8000/
```
